  - Before: The old code used groupby, which drops rows with NaN in a grouping

  Sort order

  rows). The last row is Cat, Dog, Moris, and Biatrix (4 rows).

  What path.stem means

  path.stem is the file name without its extension. For example, the file name
  000d336b….jpg gives the stem 000d336b…. The CSV holds IDs without .jpg. So the
  code removes the extension from each file name before it compares the file
  names with the IDs. If the code did not do this, every ID would look like it
  has no file.

  dropna=False is there.
