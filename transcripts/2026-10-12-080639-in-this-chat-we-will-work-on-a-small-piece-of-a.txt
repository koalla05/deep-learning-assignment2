  Cell 1 defines cross_validate_train_vs_test(embeddings, is_test). The function
  works in these steps:
  1. It splits the rows with StratifiedKFold(n_splits=5, shuffle=True, 
     random_state=RANDOM_STATE), stratified by the label.
  2. In each fold, it trains a logistic regression on four parts of the rows.
  3. It scores the fifth part with ROC AUC.
  4. It returns one score per fold.

  I put StandardScaler before the logistic regression, because the raw
  embeddings are not scaled. I set max_iter=1000 so the model can converge.

  Cell 2 builds the label and runs the function. The label is 0 for a train row
  and 1 for a test row. The rows are train_embeddings followed by
  test_embeddings, which is the order of all_embeddings from the near-copy cell.
  The cell shows the five fold scores and their mean.
